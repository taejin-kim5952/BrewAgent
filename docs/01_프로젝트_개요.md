# 1. 프로젝트 개요

← [← README로 돌아가기](../README.md)

---

## 목적
VSCode + Continue.dev 환경에서 개발자의 질문에 답하는 로컬 AI 서버이며, 동시에 대화 내역을 수집하여 모델 파인튜닝용 데이터셋을 만드는 플랫폼.

---

## 핵심 기능

| 기능 | 설명 |
|---|---|
| **RAG 채팅** | 업로드된 문서를 참고해 Ollama(Gemma 등) 로컬 LLM으로 답변 |
| **멀티모달 인제스트** | PDF / Word / PPT / Excel / 이미지(OCR) / 코드(.java .sql 등) / 텍스트 인덱싱 |
| **압축 파일 지원** | ZIP/TAR 업로드 시 내부 모든 파일 자동 추출·인덱싱 |
| **하이브리드 검색** | FAISS 벡터 검색 + SQLite FTS5 BM25를 RRF로 결합 |
| **LLM 자동 라우팅** | 질문 복잡도에 따라 빠른 모델 ↔ 정확한 모델 자동 선택 |
| **문서 요약** | 업로드 문서를 Ollama로 자동 요약 (긴 문서는 map-reduce) |
| **가이드 → 규칙 추출** | 회사 보안/품질 가이드 PDF → AI가 규칙 단위로 자동 분할 |
| **Q&A 자동 생성** | 규칙 → 코드 리뷰/생성/개념/거절 4종 학습 데이터 합성 |
| **훈련 데이터 수집** | 모든 Q&A 자동 기록 + 평가 + JSONL 내보내기 |
| **웹 UI** | 4개 탭(대화 내역 / 수동 입력 / 문서 요약 / 가이드 변환) |
| **Continue.dev 연동** | OpenAI 호환 API로 VSCode와 바로 연결 |

---

## 아키텍처

```
[VSCode + Continue.dev]
        │  POST /v1/chat/completions
        ▼
[RAG Server :8000]  ←── start.bat 실행
   ├─ QueryIntelligence (의도 분석 + 쿼리 재작성)
   ├─ HybridRetriever (FAISS + FTS5)
   ├─ ContextOptimizer (중복 제거 + 토큰 예산)
   ├─ PromptBuilder (의도별 시스템 프롬프트)
   ├─ LLMRouter → OllamaBackend (gemma4 / qwen2.5-coder 등)
   └─ EvaluationEngine + InteractionLogger (백그라운드)
        │
        ▼
[Ollama :11434]  ←── ollama serve 실행
   └─ 로컬 LLM 모델

[웹 UI 탭 4개]
  1. Continue.dev 대화 내역 — 평점·필터·내보내기
  2. 수동 데이터 입력 — Q&A 직접 추가
  3. 문서 요약 — 업로드 → AI 요약
  4. 가이드 → 훈련 데이터 — Phase 1+2 통합

[스토리지]  D:\RAGPlatform\storage\
   ├─ indices/{namespace}/    ← FAISS 인덱스 (.faiss + .pkl)
   ├─ metadata.db             ← 청크 메타 + FTS5
   ├─ interactions.db         ← Q&A 기록 + 평가 + 가이드/규칙/Q&A
   └─ exports/                ← 내보낸 JSONL 파일
```

## 핵심 흐름

### 1) RAG 채팅 흐름
```
사용자 질문 (Continue.dev)
   ↓ Ollama 호환 API
RAG 서버
   ↓ 1. 의도 분석 + 쿼리 재작성
   ↓ 2. FAISS + BM25 하이브리드 검색
   ↓ 3. 컨텍스트 최적화 (중복 제거 + 토큰 예산)
   ↓ 4. 프롬프트 조립 (의도별 시스템 프롬프트)
   ↓ 5. LLM 라우팅 (복잡도 기반)
Ollama → 답변 생성
   ↓ 백그라운드: 자동 평가 + 로깅
사용자에게 응답 + 인터랙션 DB 저장
```

### 2) 가이드 → 훈련 데이터 흐름 (Phase 1+2)
```
[Phase 1] 가이드 PDF/Word 업로드
   ↓ Dispatcher 파싱
   ↓ AI가 규칙 단위로 분할 (LLM)
   ↓ 사용자 검수 (편집/병합/분할)
   ↓ 구조 확정

[Phase 2] Q&A 자동 생성
   ↓ 규칙당 5개 생성 (코드리뷰 50% / 코드생성 30% / 개념 15% / 거절 5%)
   ↓ 사용자 검수 (승인/거절/편집)
   ↓ 승인된 Q&A만 저장

[내보내기] JSONL 파일
   ↓ Continue.dev 인터랙션 + 수동 입력 + 가이드 Q&A 통합
   ↓ Alpaca / OpenAI / ShareGPT 형식 선택
   ↓ Colab에서 LoRA 파인튜닝
```

## 보안 / 프라이버시

- **모든 처리 로컬 실행** (LLM 추론 + 임베딩 + DB)
- 외부 API 호출 없음 (`force_local: true` 기본값)
- 압축 파일 처리 시 Zip-slip 방어 + 1GB / 1000파일 가드
- 임시 추출 파일은 처리 후 즉시 삭제
