## 카테고리별 역할

### 웹 서버
| 라이브러리 | 역할 |
|---|---|
| `fastapi` | REST API 프레임워크 |
| `uvicorn[standard]` | ASGI 서버 (자동 리로드 포함) |
| `python-multipart` | 파일 업로드 폼 처리 |

### 데이터 검증/설정
| 라이브러리 | 역할 |
|---|---|
| `pydantic` | 요청/응답 데이터 검증 + 모델 정의 |
| `pydantic-settings` | YAML 설정 자동 매핑 |
| `pyyaml` | default.yaml / local.yaml 파싱 |

### 임베딩/벡터 검색
| 라이브러리 | 역할 |
|---|---|
| `sentence-transformers` | 텍스트 → 384차원 벡터 변환 (all-MiniLM-L6-v2) |
| `faiss-cpu` | 벡터 인덱스 + 유사도 검색 |
| `rank-bm25` | BM25 점수 계산 (FTS5 보조용) |

### LLM 호출
| 라이브러리 | 역할 |
|---|---|
| `httpx` | 비동기 HTTP 클라이언트 (Ollama/OpenAI 호출) |

### 문서 파싱
| 라이브러리 | 역할 | 지원 형식 |
|---|---|---|
| `pymupdf` | PDF 텍스트/이미지 추출 | .pdf |
| `python-docx` | Word 문서 파싱 | .docx |
| `python-pptx` | PowerPoint 슬라이드 파싱 | .pptx |
| `openpyxl` | Excel 시트 → 마크다운 테이블 | .xlsx, .xlsm |
| `pillow` | 이미지 로드/전처리 | .jpg, .png 등 |
| `pytesseract` | Tesseract OCR 래퍼 | 이미지 → 텍스트 |
| `tree-sitter` | 코드 AST 파싱 | .java, .sql 등 |

### 데이터베이스
| 라이브러리 | 역할 |
|---|---|
| `aiosqlite` | 비동기 SQLite 드라이버 |
| `sqlalchemy` | ORM (현재 raw SQL 위주, 미래 확장용) |

### 로깅/유틸
| 라이브러리 | 역할 |
|---|---|
| `loguru` | 구조화된 컬러 로깅 |
| `anyio` | 비동기 동시성 헬퍼 |

## Python 표준 라이브러리 의존

추가 설치 없이 사용 중:
- `zipfile`, `tarfile` — 압축 파일 처리
- `tempfile` — 임시 디렉터리
- `asyncio` — 백그라운드 task
- `pathlib` — 경로 조작
- `json` — JSONL 입출력
- `re` — LLM 응답 JSON 추출 (정규식)

## 버전 호환성 메모

- **`pydantic 2.12.x`**: 2.7.x는 cp313 wheel이 없어서 Python 3.13 환경에서 빌드 실패 발생. 업그레이드 필요.
- **`faiss-cpu 1.13.x`**: 1.8.0은 Python 3.13 wheel 누락. 1.13+ 사용해야 함. API는 IndexFlatL2 호환.
- **`tree-sitter 0.25.x`**: 0.22.3은 cp313 win wheel 없음.
- **`pillow 11.x`**: numpy 2.x 호환 위해 11.x 권장.
