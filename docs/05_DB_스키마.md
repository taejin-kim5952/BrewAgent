## 두 개의 SQLite 파일

| 파일 | 용도 | 주요 테이블 |
|---|---|---|
| `metadata.db` | 인덱싱된 문서·청크 메타 + 전문 검색 | documents, chunks, chunks_fts |
| `interactions.db` | 인터랙션 + 가이드 + 학습 데이터 | interactions, eval_scores, manual_entries, guides, rules, generated_qa |

---

## metadata.db

### documents
인덱싱된 문서의 메타데이터.

```sql
CREATE TABLE documents (
    doc_id      TEXT PRIMARY KEY,
    namespace   TEXT,
    source_path TEXT,
    doc_type    TEXT,   -- pdf, docx, pptx, excel, image, code, text, archive
    title       TEXT,
    created_at  TEXT,
    metadata    TEXT    -- JSON
);
```

### chunks
청크(텍스트 조각).

```sql
CREATE TABLE chunks (
    chunk_id        TEXT PRIMARY KEY,
    doc_id          TEXT REFERENCES documents,
    namespace       TEXT,
    content         TEXT,
    chunk_index     INTEGER,
    page_or_line    INTEGER,
    language        TEXT,
    token_count     INTEGER,
    embedding_model TEXT,
    created_at      TEXT,
    metadata        TEXT
);
```

### chunks_fts
FTS5 가상 테이블 (전문 검색 BM25용).

```sql
CREATE VIRTUAL TABLE chunks_fts USING fts5(
    content,
    chunk_id,
    namespace,
    tokenize='unicode61'
);
```

`MetadataStore.upsert_chunk()` 호출 시 chunks와 chunks_fts에 동시 삽입.

## interactions.db

### interactions
모든 Continue.dev 채팅 Q&A 기록.

```sql
CREATE TABLE interactions (
    interaction_id  TEXT PRIMARY KEY,
    namespace       TEXT,
    query           TEXT NOT NULL,
    rewritten_query TEXT,
    intent          TEXT,            -- code_generation, debugging, ...
    response        TEXT NOT NULL,
    model_used      TEXT,
    routing         TEXT,            -- LOCAL_FAST / LOCAL_FULL / EXTERNAL
    chunk_ids       TEXT,            -- JSON 배열
    eval_score      REAL,            -- 0.0~1.0 종합 점수
    user_rating     INTEGER,         -- 1~5 사용자 평점
    latency_ms      INTEGER,
    created_at      TEXT,
    context_text    TEXT
);

CREATE INDEX idx_interactions_namespace ON interactions(namespace);
CREATE INDEX idx_interactions_rating ON interactions(user_rating);
CREATE INDEX idx_interactions_created ON interactions(created_at);
```

### eval_scores
각 Scorer별 상세 점수.

```sql
CREATE TABLE eval_scores (
    eval_id        TEXT PRIMARY KEY,
    interaction_id TEXT REFERENCES interactions,
    scorer         TEXT,    -- relevance / faithfulness / code_quality
    score          REAL,
    feedback       TEXT,
    created_at     TEXT
);
```

### manual_entries
사용자 수동 입력 Q&A.

```sql
CREATE TABLE manual_entries (
    entry_id    TEXT PRIMARY KEY,
    instruction TEXT NOT NULL,
    output      TEXT NOT NULL,
    created_at  TEXT
);

CREATE INDEX idx_manual_created ON manual_entries(created_at);
```

### guides (Phase 1)
업로드된 가이드 메타데이터.

```sql
CREATE TABLE guides (
    guide_id    TEXT PRIMARY KEY,
    name        TEXT NOT NULL,         -- 사용자 입력 별칭
    source_file TEXT,                  -- 원본 파일명
    page_count  INTEGER DEFAULT 0,
    status      TEXT DEFAULT 'parsing',-- parsing | extracting | done | failed
    progress    INTEGER DEFAULT 0,     -- 0~100
    error_msg   TEXT,
    created_at  TEXT,
    updated_at  TEXT
);

CREATE INDEX idx_guides_status ON guides(status);
```

### rules (Phase 1)
가이드에서 추출된 개별 규칙.

```sql
CREATE TABLE rules (
    rule_id        TEXT PRIMARY KEY,
    guide_id       TEXT REFERENCES guides ON DELETE CASCADE,
    section_label  TEXT,            -- "§3.2.1" 또는 "AUTO-001"
    title          TEXT,
    body           TEXT,
    category       TEXT,            -- 보안 / 품질 / 네이밍 / ...
    severity       TEXT,            -- must / should / may / unknown
    code_bad       TEXT DEFAULT '',
    code_good      TEXT DEFAULT '',
    source_pages   TEXT DEFAULT '', -- "12,13,14"
    order_index    INTEGER DEFAULT 0,
    reviewed       INTEGER DEFAULT 0, -- 사용자 검수 완료 (0/1)
    user_edited    INTEGER DEFAULT 0,
    deleted        INTEGER DEFAULT 0, -- 소프트 삭제
    created_at     TEXT
);

CREATE INDEX idx_rules_guide ON rules(guide_id);
CREATE INDEX idx_rules_category ON rules(category);
```

### generated_qa (Phase 2)
규칙으로부터 합성된 Q&A.

```sql
CREATE TABLE generated_qa (
    qa_id        TEXT PRIMARY KEY,
    rule_id      TEXT REFERENCES rules ON DELETE CASCADE,
    guide_id     TEXT REFERENCES guides ON DELETE CASCADE,
    qa_type      TEXT DEFAULT 'code_review',
                              -- code_review / code_gen / concept / refusal
    instruction  TEXT NOT NULL,
    output       TEXT NOT NULL,
    status       TEXT DEFAULT 'pending',
                              -- pending / approved / rejected
    user_edited  INTEGER DEFAULT 0,
    created_at   TEXT
);

CREATE INDEX idx_qa_rule ON generated_qa(rule_id);
CREATE INDEX idx_qa_guide ON generated_qa(guide_id);
CREATE INDEX idx_qa_status ON generated_qa(status);
```

## 데이터 흐름 (인터랙션 → JSONL 내보내기)

```
[사용자 채팅]
   ↓
interactions 테이블 (자동 저장)
   ↓ 백그라운드 평가
eval_scores 테이블 (점수 저장)
   ↓ interactions.eval_score 업데이트

[사용자 수동 입력]
   ↓
manual_entries 테이블

[가이드 업로드]
   ↓
guides 테이블 (status='parsing')
   ↓ AI 분석
rules 테이블 (규칙별 INSERT)
   ↓ guides.status='done'

[Q&A 생성]
   ↓
generated_qa 테이블 (status='pending')
   ↓ 사용자 승인
generated_qa.status='approved'

[내보내기]
   ↓ POST /v1/dataset/export
interactions + manual_entries + generated_qa(approved)
   ↓ 통합 → JSONL 변환
exports/finetune_*.jsonl
```

## SQLite 직접 조회 예시

```python
import sqlite3
conn = sqlite3.connect('D:/RAGPlatform/storage/interactions.db')
conn.row_factory = sqlite3.Row

# 가이드 진행 상태 한눈에
for g in conn.execute(
    "SELECT name, status, progress FROM guides ORDER BY updated_at DESC"
):
    print(f"{g['name']}: {g['status']} {g['progress']}%")

# 카테고리별 규칙 분포
for r in conn.execute(
    "SELECT category, COUNT(*) FROM rules WHERE deleted=0 GROUP BY category"
):
    print(r)

# Q&A 유형별 승인 비율
for r in conn.execute("""
    SELECT qa_type, status, COUNT(*) FROM generated_qa
    GROUP BY qa_type, status ORDER BY qa_type, status
"""):
    print(r)
```
