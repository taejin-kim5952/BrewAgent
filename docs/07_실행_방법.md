## 빠른 시작 (최초 1회)

### 1. 사전 설치
| 항목 | 다운로드 | 비고 |
|---|---|---|
| Python 3.10+ | https://www.python.org/downloads/ | "Add to PATH" 체크 필수 |
| Ollama | https://ollama.com/download | Windows 설치본 |
| Tesseract (선택) | https://github.com/UB-Mannheim/tesseract/wiki | 이미지 OCR용 |

### 2. 인스톨러 실행
```
D:\튜닝\RAGPlatform_Setup\setup.bat  더블클릭
```

자동 진행:
- venv 생성 → pip install (15~30분)
- Ollama 모델 다운로드 (선택 가능)
- `D:\RAGPlatform\` 또는 `C:\RAGPlatform\`에 설치

### 3. 모델 다운로드
```bash
ollama pull gemma3:1b      # 테스트용 (0.8GB, 빠름)
ollama pull gemma4:e4b     # 권장 (~3GB, 한국어 균형)
ollama pull qwen3.5:4b     # 코드 작업 (3.2GB)
```

## 서버 시작

### 배포본 (setup.bat 실행 후)
```
D:\RAGPlatform\start.bat  더블클릭
```

내부 동작:
```batch
set PYTHONIOENCODING=utf-8
set PYTHONUTF8=1
call "D:\RAGPlatform\venv\Scripts\activate.bat"
cd /d "D:\RAGPlatform"
python -m uvicorn rag.server.main:app --host 0.0.0.0 --port 8000 --reload
```

### 개발본 (소스 직접 실행)
```powershell
cd D:\튜닝\RAGPlatform_Setup
.\dev_run.ps1
```

> **중요**: `rag` 패키지명은 Python 표준 라이브러리 `platform`과 이름 충돌 문제로 `platform/` → `rag/`로 변경됨. uvicorn은 반드시 `RAGPlatform` 디렉터리에서 `rag.server.main:app`으로 실행해야 함.

## Ollama 별도 실행

```bash
# 1. Ollama 서버 시작 (한 번만)
ollama serve

# 2. 모델 다운로드 (한 번만)
ollama pull gemma3:1b

# 3. 모델 정상 동작 테스트
ollama run gemma3:1b
> 안녕
> /bye

# 4. 활성 모델 확인
curl http://localhost:11434/api/ps
```

## 서버 중지

### 정상 종료
- 터미널 창에서 `Ctrl+C`

### 멈춤 시 강제 종료
```powershell
taskkill /f /im python.exe
```
(다른 Python 프로세스도 함께 종료되니 주의)

### 좀비 모델 언로드
긴 추론 후 모델이 메모리 점유 시:
```powershell
curl http://localhost:11434/api/generate -X POST -H "Content-Type: application/json" --data "{\"model\":\"gemma4:latest\",\"keep_alive\":0,\"prompt\":\"\"}"
```

## 자주 쓰는 진단 명령

### 가이드 진행 상태 확인
```powershell
PYTHONIOENCODING=utf-8 python -c "
import sqlite3
conn = sqlite3.connect('D:/RAGPlatform/storage/interactions.db')
conn.row_factory = sqlite3.Row
for g in conn.execute('SELECT name,status,progress,error_msg FROM guides ORDER BY updated_at DESC LIMIT 5'):
    print(dict(g))
"
```

### Ollama 활성 모델 확인
```bash
curl http://localhost:11434/api/ps
```
- `size_vram` > 0 → GPU 사용 중 (정상)
- `size_vram` = 0 → CPU만 사용 (느림)

### 인덱싱된 청크 수 확인
```bash
curl http://localhost:8000/v1/collections
```

## 설정 변경 시

`rag/configs/local.yaml` 수정 → **서버 재시작 필수**

```yaml
ollama:
  model_fast: "gemma3:1b"
  model_full: "gemma3:1b"
```

설정 파일 변경만으로는 적용 안 됨. 반드시 서버를 끄고 다시 실행.
