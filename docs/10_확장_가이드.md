## 새 평가 Scorer 추가

답변 품질을 다른 기준으로 채점.

### 1. Scorer 클래스 작성

`rag/evaluation/scorers/length_balance.py`:
```python
from .base import Scorer, ScoreResult

class LengthBalanceScorer(Scorer):
    """답변이 너무 짧거나 길지 않은지 평가."""

    @property
    def name(self) -> str:
        return "length_balance"

    async def score(self, query, answer, context) -> ScoreResult:
        ideal_min, ideal_max = 100, 1000
        length = len(answer)
        if length < ideal_min:
            score = length / ideal_min * 0.5
        elif length > ideal_max:
            score = max(0.5, 1 - (length - ideal_max) / 2000)
        else:
            score = 1.0
        return ScoreResult(
            scorer=self.name,
            score=score,
            passed=score >= 0.7,
            feedback=f"길이 {length}자",
        )
```

### 2. EvaluationEngine에 등록

`rag/evaluation/engine.py`:
```python
from .scorers.length_balance import LengthBalanceScorer

class EvaluationEngine:
    def __init__(self):
        self.scorers = [
            RelevanceScorer(),
            FaithfulnessScorer(),
            CodeQualityScorer(),
            LengthBalanceScorer(),  # ← 추가
        ]
```

자동으로 모든 인터랙션에서 채점되어 `eval_scores` 테이블에 저장됨.
