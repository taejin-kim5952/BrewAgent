## 설치 후 디렉터리 (`D:\RAGPlatform\`)

```
D:\RAGPlatform\
├── rag/                            ← 메인 패키지 (Python)
│   ├── __init__.py
│   ├── configs/
│   │   ├── default.yaml            ← 기본 설정값 (git 추적)
│   │   ├── local.yaml              ← 로컬 오버라이드 (gitignore)
│   │   └── settings.py             ← Pydantic 설정 모델 + 로더
│   ├── server/
│   │   ├── main.py                 ← FastAPI 앱 진입점
│   │   ├── dependencies.py         ← AppContainer (싱글톤 의존성 컨테이너)
│   │   ├── access_log_middleware.py← HTTP 액세스 로그 미들웨어
│   │   ├── static/
│   │   │   └── index.html          ← 훈련 데이터 관리 웹 UI (4개 탭)
│   │   └── routes/
│   │       ├── chat.py             ← POST /v1/chat/completions
│   │       ├── ingest.py           ← /v1/ingest/file, /batch, /summarize
│   │       ├── collections.py      ← /v1/collections/*
│   │       ├── dataset.py          ← /v1/dataset/* (인터랙션, 수동입력, 내보내기)
│   │       ├── eval.py             ← /v1/eval/run
│   │       └── guide.py            ← /v1/guide/* (가이드 + 규칙 + Q&A)
│   ├── ingest/
│   │   ├── pipeline.py             ← IngestPipeline (parse→chunk→embed→store)
│   │   ├── dispatcher.py           ← 확장자별 파서 라우팅
│   │   ├── chunker.py              ← 텍스트 청킹 전략
│   │   ├── embedder.py             ← sentence-transformers 배치 임베딩
│   │   └── parsers/
│   │       ├── base.py             ← TextChunk, ParseResult, BaseParser ABC
│   │       ├── pdf_parser.py       ← PyMuPDF 기반 PDF
│   │       ├── docx_parser.py      ← python-docx (Word)
│   │       ├── pptx_parser.py      ← python-pptx (PowerPoint)
│   │       ├── excel_parser.py     ← openpyxl → 마크다운 테이블
│   │       ├── image_parser.py     ← Pillow + pytesseract OCR
│   │       ├── code_parser.py      ← Java/SQL/Python 등 코드
│   │       └── text_parser.py      ← .txt/.md/.csv 등 폴백
│   ├── vector_db/
│   │   ├── store.py                ← FAISSStore (네임스페이스별 파일 분리)
│   │   ├── namespace.py            ← NamespaceManager (경로 관리)
│   │   ├── metadata_store.py       ← MetadataStore (SQLite + FTS5)
│   │   └── schemas.py              ← DocumentRecord, ChunkRecord, SearchResult
│   ├── query/
│   │   ├── intelligence.py         ← QueryIntelligence (의도 분류 + 복잡도 평가)
│   │   ├── retriever.py            ← HybridRetriever (FAISS + BM25 + RRF)
│   │   └── context_optimizer.py    ← 중복 제거 + 토큰 예산 적용
│   ├── llm_router/
│   │   ├── router.py               ← LLMRouter (복잡도 기반 백엔드 선택)
│   │   ├── prompt_builder.py       ← PromptBuilder (의도별 시스템 프롬프트)
│   │   ├── prompts/
│   │   │   ├── rule_extraction.py  ← 가이드 → 규칙 추출 프롬프트
│   │   │   └── qa_generation.py    ← 규칙 → Q&A 변환 프롬프트
│   │   └── backends/
│   │       ├── base.py             ← LLMBackend ABC, GenerateParams
│   │       ├── ollama_backend.py   ← Ollama API 연동
│   │       └── openai_backend.py   ← OpenAI/외부 API 폴백
│   ├── evaluation/
│   │   ├── engine.py               ← EvaluationEngine (비동기 병렬 채점)
│   │   └── scorers/
│   │       ├── base.py             ← Scorer ABC, ScoreResult
│   │       ├── relevance.py        ← 쿼리-답변 단어 겹침 비율
│   │       ├── faithfulness.py     ← 답변-컨텍스트 근거 비율
│   │       └── code_quality.py     ← Python 코드 블록 파싱 가능 여부
│   ├── memory/
│   │   ├── cache.py                ← ResponseCache (TTL 기반 인메모리)
│   │   └── knowledge_store.py      ← KnowledgeStore (FAQ, JSON 파일)
│   ├── dataset/
│   │   ├── interaction_logger.py   ← InteractionLogger + 수동 입력 (SQLite)
│   │   ├── guide_store.py          ← GuideStore (가이드/규칙/Q&A 테이블)
│   │   └── exporter.py             ← JSONLExporter (OpenAI/Alpaca/ShareGPT)
│   └── tools/
│       ├── registry.py             ← ToolRegistry + default_registry()
│       ├── executor.py             ← ToolExecutor
│       └── builtin/
│           ├── db_query.py         ← SELECT 쿼리 실행 도구
│           └── code_runner.py      ← Python 코드 실행 도구
├── venv/                           ← Python 가상환경
├── storage/                        ← 런타임 데이터
│   ├── indices/{namespace}/
│   │   ├── index.faiss
│   │   └── id_map.pkl
│   ├── metadata.db                 ← 문서·청크 메타데이터 + FTS5
│   ├── interactions.db             ← 인터랙션 + 가이드/규칙/Q&A
│   └── exports/                    ← 내보낸 JSONL 파일
├── requirements.txt
├── start.bat                       ← 서버 시작
└── stop.bat                        ← 서버 중지
```

## 배포 패키지 디렉터리 (`D:\튜닝\RAGPlatform_Setup\`)

```
D:\튜닝\RAGPlatform_Setup\          ← GitHub에 올라가는 소스 트리
├── setup.bat                       ← 원클릭 인스톨러 (Windows)
├── dev_run.ps1                     ← 개발용 서버 실행 (PowerShell)
├── dev_start.bat                   ← 개발용 서버 실행 (cmd)
├── install.py                      ← 인스톨러 보조 스크립트
├── requirements.txt
├── README.md                       ← GitHub 메인 페이지용
├── LICENSE
├── .gitignore
├── rag/                            ← 위 설치본 rag/와 동일
└── assets/                         ← 아이콘 등
```

> **주의**: `D:\튜닝\RAGPlatform_Setup\`은 개발/배포용 소스이고, `D:\RAGPlatform\`은 setup.bat 실행 시 생성되는 설치본입니다. 개발 중에는 `D:\튜닝\RAGPlatform_Setup\`에서 직접 `dev_run.ps1`로 실행하면 setup 없이도 동작합니다.

## 모듈 간 의존성

```
server/main.py (진입점)
   ↓
server/dependencies.py (AppContainer 싱글톤)
   ├→ configs/settings.py
   ├→ ingest/ (Dispatcher, Chunker, Embedder, IngestPipeline)
   ├→ vector_db/ (FAISSStore, MetadataStore, NamespaceManager)
   ├→ query/ (QueryIntelligence, HybridRetriever, ContextOptimizer)
   ├→ llm_router/ (LLMRouter, OllamaBackend, OpenAIBackend, PromptBuilder)
   ├→ evaluation/ (EvaluationEngine + scorers)
   ├→ memory/ (ResponseCache, KnowledgeStore)
   ├→ dataset/ (InteractionLogger, GuideStore, JSONLExporter)
   └→ tools/ (ToolRegistry, ToolExecutor)

server/routes/*.py
   └→ container.* 로 모든 컴포넌트 접근
```
